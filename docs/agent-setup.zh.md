# 用 AI 智能体搭建 CitePo 博客

把下面这一句发给你的 AI 智能体（Claude Code、Codex、OpenClaw、Cursor，或任何能执行命令的智能体）：

```
帮我搭建 CitePo 博客：https://citepo.com/agent-setup.md
```

第一次用 CitePo：智能体会安装 `citepo` 命令行工具和配套的 skill，创建博客，和你一起写好第一篇文章，并把博客发布上线。

已经有 CitePo 博客：告诉智能体「我已经有博客了」。它会帮你登录，把博客下载到这台电脑上，之后就由它帮你写文章、发布文章。

过程中它会请你确认安装、在浏览器里批准 CitePo 登录；第一次使用时，还要在浏览器里允许 GitHub 访问。
