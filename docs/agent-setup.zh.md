# 用 AI 智能体搭建 CitePo 博客

把下面这一句发给你的 AI 智能体（Claude Code、Codex、OpenClaw、Cursor，或任何能执行命令的智能体）：

```
帮我搭建 CitePo 博客：https://citepo.com/agent-setup.md
```

智能体会安装 `citepo` 命令行工具和配套的 skill，创建博客，和你一起写好第一篇文章，并把博客发布上线。
过程中它会请你确认安装，并请你在浏览器里完成两步操作：登录 GitHub（如果还没登录），以及在 citepo.com 上连接仓库。

---

## 给 AI 智能体

请按英文版 https://citepo.com/agent-setup.md 中「To the AI agent」一节的步骤执行，用用户的语言与用户沟通。
